petwell-zern.vercel.app

PetWell

Solo project · Pet health records & vet appointments

Your pet’s health, wherever you go.

A pet health record that the owner keeps and every vet can add to. Each entry shows which clinic wrote it.

The problem

A pet's medical history lives inside whichever clinic wrote it. Change clinics and the history stays behind. Version 1 also let any clinic read every pet.

What I built

  • Separate Pet Owner and Clinic Staff roles (JWT + RBAC)
  • V2 consent rules: a clinic sees a pet only through a confirmed appointment or a one-time 6-digit share code from the owner
  • Audit log on every record a clinic opens

How I worked

Before coding I wrote user stories, an ERD, an endpoint list, a change request with an impact analysis and a decision log (54 decisions). I built from those documents section by section with AI, then tested every flow as both owner and staff. 88 Vitest tests run against a real database.
